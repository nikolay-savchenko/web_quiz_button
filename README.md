# Квиз-кнопка

Веб-кнопка для «Своей игры»: команды жмут на кнопку на своих телефонах, а на экране ведущего видно, кто нажал первым, порядок остальных и разницу в миллисекундах.

- **Честное «кто первый».** Телефоны постоянно синхронизируют часы с сервером. Порядок определяется по моменту нажатия, а не по тому, чей пакет быстрее долетел. Кнопки у всех загораются одновременно, в момент `armAt` по синхронизированным часам.
- **Фальстарт.** Если нажать до открытия кнопок, команда блокируется на N секунд (настраивается, можно выключить).
- **Неверный ответ.** Команда получает минус и выбывает из этого вопроса, а кнопки сразу открываются остальным.
- **Счёт** хранится в `data/state.json` и переживает перезапуск сервера.
- **Несколько телефонов на команду.** Засчитывается самое раннее нажатие.
- QR-код для подключения, звуки на экране ведущего, вибрация на Android.

## Приколы

Прикол выпадает **всем командам одинаково** на одно открытие кнопок. У каждого прикола своя вероятность, она задаётся в «Настройках» на экране ведущего (по умолчанию в сумме около 16%). Через выпадающий список «Прикол на следующее открытие» можно принудительно включить конкретный прикол, «любой прикол» или «любую капчу».

- **Бегающая кнопка.** Перед открытием кнопка сжимается в кружок, который летает по экрану и отскакивает от краёв. Засчитывается только попадание по кружку.
- **Свайп.** «Смахни ВПРАВО»: засчитывается, когда палец прошёл 50% экрана в нужную сторону.
- **Двойной свайп.** Сначала показывается одно направление, а после него внезапно «а теперь смахни ВВЕРХ». Комбинация случайная (любая из 16, в том числе «вправо, потом влево»), но одна для всех. Свайп не в ту сторону сбрасывает прогресс.
- **Капча «самый грустный смайлик».** Шесть смайлов, правильный ответ один для всех: самый грустный по шкале 😀🙂😐😕🙁😟😔😞😢😭. Ошибка блокирует на 1,5 с.
- **Капча «найди лишний»**, два уровня: сетка 5×5 и 10×10 (у каждого своя вероятность). Ищем 🙃 среди 🙂 или 🐶 среди 🐱 (и наоборот). Ошибка блокирует на 1,5 с.

На экране ведущего показывается название прикола. Ответ капчи и направления двойного свайпа видны только во всплывающей подсказке при наведении мышкой, на случай если экран выведен на проектор.

**🎯 Кнопка у одного** (кнопка или клавиша `O` у ведущего). В каждой команде случайно выбирается один подключённый телефон, и только его нажатие засчитывается до конца вопроса. Заранее об этом не объявляется: остальные узнают, только когда откроются кнопки («Кнопка не у тебя 🙃»). Повторный клик выбирает заново, «Новый вопрос» выключает режим.

## Быстрый запуск на сервере (Ubuntu 22.04 / 24.04)

Нужен root и открытые порты 80 и 443:

```bash
curl -fsSL https://raw.githubusercontent.com/nikolay-savchenko/web_quiz_button/main/deploy/install.sh | bash
```

Скрипт ставит Node.js 20 и Caddy, поднимает systemd-сервис `quiz` и сам получает HTTPS-сертификат. Если домен не задан, используется `<ip-через-дефисы>.sslip.io`, так что свой домен не обязателен. В конце скрипт печатает ссылки для игроков и ведущего.

Со своим доменом (A-запись должна указывать на сервер) и своим ключом ведущего:

```bash
DOMAIN=quiz.example.ru HOST_KEY=мой-секрет bash install.sh
```

Чтобы обновить код, запусти тот же скрипт ещё раз. Настройки лежат в `/opt/web_quiz_button/.env`.

## Локально

```bash
npm install
HOST_KEY=demo npm start
# игроки:  http://<ip-ноутбука>:3000/
# ведущий: http://localhost:3000/host?key=demo
```

Телефоны должны быть в той же сети, что и ноутбук.

## Тест честности

```bash
npm test
```

Тест симулирует три телефона с разной сетью (пинг от ~10 до ~600 мс, джиттер) и сбитыми часами (±5 с) и проверяет, что побеждает тот, кто нажал раньше.

## Ведущий: горячие клавиши

| Клавиша | Действие |
|---|---|
| Пробел | открыть кнопки |
| Enter | верно (+цена вопроса) |
| Backspace | неверно (−цена, остальные могут жать) |
| Esc | новый вопрос / сброс |
| Q | показать QR крупно |
| O | кнопка у одного (повтор — перевыбрать) |

Звук включается кнопкой «Включить звук»: браузер не даёт играть звук без клика.

## Настройки (env)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | 3000 | порт приложения |
| `HOST_KEY` | случайный | ключ для экрана ведущего |
| `PUBLIC_URL` | из заголовков | адрес для QR-кода |
| `ARM_DELAY_MS` | 400 | через сколько после «Открыть» загораются кнопки (запас, чтобы сигнал дошёл до всех) |
| `JUDGE_WINDOW_MS` | 500 | сколько ждать опоздавшие пакеты после первого нажатия |
| `MAX_LAG_MS` | 1500 | если оценка времени нажатия старше этого, ей не доверяем |
| `DATA_FILE` | `data/state.json` | где хранить счёт |

Команды, цена вопроса и штраф за фальстарт меняются прямо на экране ведущего, в разделе «Настройки».

## Советы на игру

- Попроси игроков отключить автоблокировку экрана или держать страницу открытой. На HTTPS страница сама просит экран не гаснуть (Wake Lock).
- Зелёная точка в углу телефона значит хорошую связь, жёлтая — пинг больше 250 мс.
- Перед игрой сделай пару тестовых раундов: на экране ведущего видно, сколько телефонов подключено к каждой команде.

## Как устроено

```
server.js          — HTTP + WebSocket, логика раунда
public/sync.js     — соединение с автопереподключением + синхронизация часов (NTP-подобная)
public/play.html   — кнопка для телефона
public/host.html   — экран ведущего
deploy/install.sh  — установка на Ubuntu (Node + Caddy + systemd)
test/sim.js        — симуляция сети и проверка честности
```
